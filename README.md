# AI FNF Mod Maker

GitHub Pages-friendly client-side prototype.

## Files

- `index.html` — UI
- `app.js` — generator, AI connection, chart generation, SF2 loading, ZIP export
- `style.css` — UI styling

## GitHub Pages

Put these files at the repository root. GitHub Pages can publish a static repository with `index.html` as its entry point.

## Important

The exporter currently creates the song/chart portion and an imported SF2 copy. The next stage is to merge a real Psych Engine 1.0.4 mod template into the exporter and render the generated MIDI/events to `Inst.ogg`.
